##CLI (Command Line Interface) – Década de 70
Características:
Baseada em entrada de comandos via teclado.
Exige que o usuário memorize comandos específicos para executar tarefas.
Baixo consumo de recursos, pois não há elementos gráficos.
Utilizada principalmente por profissionais técnicos e programadores.

#Vantagens:
Alta precisão e controle sobre o sistema.
Rápida execução de tarefas para usuários experientes.
Baixo consumo de memória e processamento.

#Desvantagens:
Difícil de aprender para usuários iniciantes.
Não intuitiva, pois exige conhecimento de comandos específicos.
Pouca interatividade visual.

#Exemplos:
MS-DOS (Microsoft Disk Operating System)
Bash Shell em Unix/Linux
Windows Command Prompt (CMD)

##GUI (Graphical User Interface) – Anos 80
Características:
Introdução de elementos gráficos (janelas, botões, menus e ícones).
Permite interação com o sistema através do mouse e teclado.
Mais intuitiva e acessível para usuários leigos.
Adotada amplamente em computadores pessoais.

#Vantagens:
Fácil de usar, pois utiliza representações visuais.
Permite multitarefa com o uso de janelas.
Reduz a curva de aprendizado em comparação com CLI.

#Desvantagens:
Maior consumo de recursos computacionais.
Pode limitar a precisão e controle em algumas tarefas avançadas.
Dependência do mouse para algumas operações pode ser menos eficiente.

#Exemplos:
Microsoft Windows
macOS
Ambientes gráficos de Linux (GNOME, KDE, XFCE)

##NUI (Natural User Interface) – 2007
Características:
Baseada em interações naturais como toque, gestos e comandos de voz.
Redução da necessidade de dispositivos periféricos tradicionais (mouse, teclado).
Adotada amplamente em smartphones, tablets e assistentes virtuais.
Expansão para Realidade Aumentada (AR) e Realidade Virtual (VR).

#Vantagens:
Mais intuitiva e acessível para qualquer faixa etária.
Permite interações mais naturais, como deslizar a tela ou dar comandos de voz.
Redução de barreiras físicas (exemplo: acessibilidade para pessoas com deficiência).

#Desvantagens:
Pode não ser tão precisa quanto CLI ou GUI em tarefas complexas.
Dependência de hardware específico (telas sensíveis ao toque, sensores de movimento).
Barreiras culturais e linguísticas para comandos de voz.

#Exemplos:
Smartphones (Android, iOS) com telas sensíveis ao toque.
Assistentes virtuais como Siri, Alexa e Google Assistant.
Kinect (Microsoft Xbox) – reconhecimento de gestos.
Óculos de Realidade Aumentada e Realidade Virtual.
